# Scam detection research

## Objective

Provide reviewed guidance patterns that help people recognize scams. The accuracy of the guidance matters more than any automated verdict, and no person is accused automatically.

## Model candidates

Deterministic pattern libraries plus reviewed examples. No statistical model card is established in this repository, and no weights are distributed.

## Dataset candidates

| Dataset | License status | Consent status |
| --- | --- | --- |
| Reviewed examples only; no victim data | review required | review required |

Victim data is prohibited. No dataset has been approved or downloaded in this repository.

## Metrics to report

Guidance accuracy on reviewed examples, false-advice rate, and reviewer agreement. Record the review protocol and example set version with each result.

## Current status

No measurements in this repository. No reviewed-example evaluation is committed.

## Limitations

Patterns age quickly and can produce false advice. Guidance is informational and never an accusation or a substitute for human judgment.
