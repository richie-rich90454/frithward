# Image protection research

## Objective

Study face protection that preserves usability for consenting subjects. Independent evaluation is required; nothing is advertised as stable before review.

## Model candidates

No fixed candidate is established in this repository. Any future candidate requires a model card before evaluation.

## Dataset candidates

| Dataset                  | License status  | Consent status  |
| ------------------------ | --------------- | --------------- |
| Consented face data only | review required | review required |

No non-consensual identity dataset may be used. No dataset has been approved or downloaded in this repository.

## Metrics to report

Independent evaluation results, attack success rate, and documented demographic limitations. Record the harness version, hardware, and operating point with each result.

## Current status

No measurements in this repository. No independent evaluation is committed.

## Limitations

Demographic limitations and downstream harm are unmeasured here. A single metric never establishes protection.
