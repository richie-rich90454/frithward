# Multimodal detection research

## Objective

Evaluate audio-video synchronization cues for synthetic-media detection, with explicit attention to language and recording-quality sensitivity.

## Metrics to report

Precision, recall, false-positive rate, calibration, per-language performance, and recording-quality sensitivity. Record the harness version, hardware, and repeated-run spread.

## Current status

No measurements in this repository. No candidate has been run through the harness.

## Limitations

Language and recording-quality effects are unmeasured here. Synchronization scores are evidence for review, not proof of manipulation.
